# LA_2040 可打印外壳 v1.0

基于上传的 LA_RP2040 KiCad PCB 工程制作。这里是可切片的实体模型，不是从产品渲染图反推的网格。单位均为 **mm**。这是首版试装件，已完成数字几何检查，尚未用实物板卡和打印件验证。

## 先用哪个文件

| 文件 | 用途 |
|---|---|
| `LA2040_Print_Plate.3mf` | 推荐：上下壳两个独立对象，已按打印方向摆放；通用几何 3MF，不含打印机、耗材或切片配置 |
| `STL/Base_and_Lid_PRINT.stl` | 上下壳同一平台的 STL 替代文件，包含两个分离实体 |
| `STL/Base_PRINT.stl` | 底壳单独打印 |
| `STL/Lid_PRINT.stl` | 上盖单独打印，外表面已经朝下 |
| `STL/USB_Fit_Collar_PRINT.stl` | 先打印的小型 USB 端试装套；它不是正式外壳的第三个零件 |
| `STEP/base.step`、`STEP/lid.step` | 可在 FreeCAD、Fusion、Onshape 等 CAD 中继续修改的实体 |
| `STEP/assembly_with_PCB_reference.step` | 上下壳装配位置及 PCB 板框参考；其中 PCB 仅为定位参考，不要打印 |
| `source/build_enclosure.py` | CadQuery 参数化源文件，顶部 `P` 字典可修改间隙、开孔和高度 |
| `docs/CAD_preview.png` | 根据本包实际 CAD 几何绘制的预览 |
| `docs/verification.json` | 数字校验结果及其范围 |

3MF 与合并 STL **二选一**，不要同时导入，否则会重复打印。试装套按需要另行打印。

## 尺寸和结构

| 项目 | 数值 / 做法 |
|---|---|
| 原板板框 | 35.0 × 16.5 mm；USB 一端保留原工程的圆角轮廓 |
| 原板板厚 | 1.6 mm |
| 壳体外形 | 38.4 × 25.7 × 11.2 mm；不含螺钉头和露出的排针 |
| PCB 底面 / 顶面高度 | 距底壳外底面 4.0 / 5.6 mm |
| 壳体分合面 | Z = 6.4 mm |
| 主体底板 / 顶板 | 1.4 / 1.4 mm；USB 开口上方局部桥厚约 0.9 mm |
| PCB 平面间隙 | 侧向约 0.3 mm；后端定位台阶与板边约 0.15 mm |
| 上盖限位台阶 | 距 PCB 顶面 0.2 mm，限制晃动，不应强压 PCB |
| USB 端开口 | 12.2 mm 宽 × 6.2 mm 高，位于壳体短端；保留插头外壳余量 |
| 排针端开口 | 17.1 mm 宽 × 6.05 mm 高；PCB 后角处有小型限位台阶 |
| BOOT | 与开关中心对齐的 Ø3.2 mm 操作孔，可用细塑料杆按下 |
| PWR / STA | 与现有两个 LED 中心对齐的 Ø2.4 mm 窗口 |
| 锁合 | 两颗外径 2.0 mm、螺纹长 8 mm 的塑料用自攻/成形螺钉，常见商品标注为 M2×8；圆头或盘头 |

本设计采用实体边缘支撑、后端止挡和上盖限位，不在 PCB 上新增安装孔。螺钉位于 PCB 两侧，底壳导孔 Ø1.7 mm、上盖通孔 Ø2.3 mm，无铜螺母或热熔嵌件。不要用沉头螺钉强行挤开孔口，也不要使用更长螺钉。若手头是普通 M2 机牙螺钉，不能按“已有螺母”的方式强拧；应换用合适的塑料螺钉，或修改导孔后再试装。

与前一张外观概念图相比，落地版增加了两侧螺钉空间，宽度相应增大；BOOT 使用操作孔，没有假定开关帽高度和行程的按键推杆。上盖为完整可打印零件，透明度取决于实际材料和工艺；普通 FDM 透明 PETG 不会自动获得渲染图中的光学透明效果。

## 推荐的首次打印流程

1. **先打印 USB_Fit_Collar_PRINT.stl。** 它从正式壳体中截取 USB 端约 9.2 mm，约为完整上下壳实体体积的四分之一。将 PCB 的 USB 端从较大的后端开口推入，直到前板边接近内部止挡；检查 USB 壳、板厚高度及 LED 对位。不要把整块 PCB 强行穿过试装套。取下试装套后再安装完整外壳。
2. 在 Bambu Studio 中选择自己的打印机和耗材，导入 3MF 为模型，或导入合并 STL。**保持毫米单位、100% 比例**。3MF 不是已经切好片的 Bambu 工程，不要把里面不存在的打印配置当成已设置。
3. 首次试装可用 PLA；需要更耐用的外壳可选择 PETG。起始设置：0.4 mm 喷嘴、0.20 mm 层高、3–4 道墙、4–5 层顶底面、15–20% 填充。材料温度和风扇沿用该耗材经过校准的配置。
4. 文件已摆好方向：底壳外底面贴床，上盖外顶面贴床；USB 试装套的端面贴床。按这些方向设计为不依赖常规支撑。切片预览中确认内侧导向筋、螺钉孔和操作孔形成正常；不要自动把上盖翻回装配姿态。
5. 上盖外表面的凹刻文字位于首层附近，建议使用干净平整的打印板。孔口有象脚或毛刺时，轻修边缘再试装，不要整体缩放外壳来“修正”局部误差。

## 装配

1. 去除孔口毛刺，检查底壳内两条支撑台面平整。
2. 让 USB 朝较大的前端开口，右侧排针朝后端开口；先将 USB 端轻轻向前送入，再将 PCB 后部放低，使板底坐在两条支撑台上。确认下层排针座没有被底板顶住。
3. 装上上盖，使 BOOT 孔和指示灯窗口与器件对应，四个导向筋进入底壳槽中。上盖应能基本自然合拢，不要用螺钉硬拉到位。
4. 用两颗 2.0×8 mm 塑料用螺钉交替轻拧，刚好闭合即可。底壳有效螺纹啮合约 3.2 mm，孔底预留余量。不要使用电动工具大扭矩锁紧。
5. 检查 USB 插头能插到底、拔插时板卡不明显位移；BOOT 操作孔可触及按钮，PWR / STA 可观察，12 个排针全部可插接。

排针开口按未带外部护套的 2×6 排针设计，适合逐根杜邦线或尺寸相符的 2×6 插头。IDC 防呆盒、宽护套或特别厚的 USB 线头未做兼容承诺。USB 端口不是防水结构，两个灯窗和 BOOT 孔也是贯通孔。

## 来源与验证边界

- 板框、板厚、器件位置、接口位置来自原始 `LA_rp2040.kicad_pcb` 的解析数据，随包提供 `source/board_data.json` 和来源校验值。
- 最终 CAD 坐标为：X = KiCad X − 107，Y = 85.25 − KiCad Y，Z 向上。已处理 KiCad 屏幕坐标与 CAD 坐标的方向差异，避免把非对称 BOOT / LED 开孔做成镜像。
- J1 工程封装名是 **Palconn UTC16-G**，关联 3D 模型是 **GCT USB4105**。本版保留该模型与原始偏移，并放宽 USB 开口；**无法仅凭这份工程确认实际焊接接口的全部机械尺寸**。这也是提供 USB 试装套的原因。
- J2 使用工程指定模型及 offset / rotation；其塑料座低于 PCB 底面的部分已计入底壳空间。按该模型，塑料座与底部留有约 0.38 mm 余量。
- 其余元件没有完整供应商高度数据，使用 1.5–2.0 mm 的保守包围体检查，并留有顶部余量；实际加高器件、焊料凸起、飞线或另装元件需另行核对。
- 已检查上下壳及 PCB 的 BRep 有效性、实体数量与相交体积；STL 封闭性、网格方向、独立对象数量及放置高度；STEP 文件回读；3MF 包结构和对象数量。
- J1 检查了 20,489 个顶点/边中点/三角形面心，J2 检查了 2,174 个采样点，均未落入上下壳实体内部。此项为采样校验，并非完整曲面公差认证。
- 尚未实物试装、未测量所用打印机的孔径偏差，也未对实际电缆外壳进行碰撞校验。

## 修改及重新生成

需要 Python 3.11/3.12、CadQuery 2.7.0。生成脚本使用随包数据，不需访问网络。

```bash
python source/build_enclosure.py
python source/verify_and_preview.py
```

`P` 中可调整底面高度、壳体高度、USB 开孔、导孔尺寸和装配间隙。PCB 尺寸字段用于源数据断言，**并不是可任意换板的通用生成器**；若更换 PCB，需要同步重新提取板框、器件和连接器坐标。

`verify_and_preview.py` 和 `render_software.py` 还需要 numpy、Pillow。预览使用真实 CAD 三角网格和深度缓冲绘制，不需要显卡或在线服务；渲染工具不影响 STL / STEP 的生成。

连接器参考网格来自 KiCad 库；来源与许可证见 `source/CONNECTOR_SOURCES.md`、`source/licenses/`。外壳源文件为本次设计生成。
