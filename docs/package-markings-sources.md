# Package-top marking references

RP2040: Raspberry Pi official datasheet, section 5.1.3, Figure 168 and Table 612.
https://datasheets.raspberrypi.com/rp2040/rp2040-datasheet.pdf

The marking layout uses the reference revision RP2-B2 and literal YY/WW, XXXXXX.00 and TTT placeholders. No fitted-device revision, date or lot was supplied by the KiCad project. These are illustrative markings, not manufacturing traceability data.

Raspberry Pi logo vector: Simple Icons (CC0), depicting the Raspberry Pi trademark solely on the corresponding component.
https://github.com/simple-icons/simple-icons/blob/develop/icons/raspberrypi.svg

GD25Q64 is the KiCad part value; the exact factory laser code, suffix and lot remain unknown. This preview uses a clearly documented part-name illustration, not a claimed exact package marking.

Both renderers share the same artwork. WebGL applies it at the full package aspect ratio; Canvas projects all three texture-plane corners with the package, preventing text floating upright while the board tilts. Pin 1 agrees with the footprint-local upper-left pad quadrant for U2 and U3. Original KiCad board silkscreen is preserved.
